# ADR 0004: Node.js 22 minimum

- Status: Accepted
- Date: 2026-11-03

## Context

The initial package needs a supported, modern Node baseline without carrying compatibility code for older runtimes. Node.js 22 is the user-selected minimum.

## Decision

Declare `engines.node` as `>=22`. Test on Node 22 and newer active LTS versions when CI is introduced. Keep core code platform-neutral and avoid importing Node-only APIs.

## Consequences

- Node 18 and 20 are not supported.
- Browser, Bun, and Deno compatibility still needs explicit testing; a Node minimum does not imply those environments work.
- Web Streams and `Intl.Segmenter` may be used only behind behavior tests or feature-aware fallbacks where needed.
